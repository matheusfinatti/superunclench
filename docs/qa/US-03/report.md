- **Build:** debug, installed from Android Studio (Sync Project with Gradle Files → Run 'app') on the `Pixel 9` AVD (API 37.2). The Android Studio build succeeded ("Install successfully finished"). The Gradle build gate was already green: assembleDebug, assembleRelease and 48 unit tests.
- **Date:** 2026-09-30 · **Tester:** QA agent
- **Result:** 7 PASS (AC4 was simulated with a QA preview toggle) · 0 FAIL · 0 NOT TESTABLE. No blocking bugs. There are 3 minor findings: an app bug (B1), a debug-panel bug (B2) and an unconfirmed observation (B3).

The permission flow was tested for real. After install the readout showed `Notif perm: denied` ([01](01-readout-before-perm-denied.png)). I tapped **Don't allow** once and then **Allow** on the second request, so the permission was never permanently denied.

Behaviour note (not a bug): pressing Fire alarm now while a check-in is already pending replaces the notification and counts the earlier one as **Missed** (`Misses: 1 consecutive`, History +1). This is consistent with US-07's rule that misses are detected by the next alarm. The next Good reset Misses to 0.

## Visual deviations from `docs/design/US-03-start-and-checkin.md`
1. **Notification action colours.** On API 37 the Good/Bad labels use the system accent (blue), not green/red. This is the expected Option A result on modern Pixel builds (§4.3), and the word labels keep the meaning. Designer to decide whether the Option B spike is still wanted.
2. **Notification and launcher icon.** The heads-up and the shade show the default green Android icon. This is the same placeholder as B1 and outside US-03.
3. **Notifications-off banner.** The `tertiaryContainer` banner is quite saturated pink/lilac in light mode next to the neutral disclaimer card. It follows the §6 token. Designer to confirm.
4. **Blocked-state sheet.** "Notifications are turned off for SuperUnclench…" with **Open settings** matches §3 state B ([36](36-rationale-blocked-dark.png)). It was only viewed through its preview button, because the real permanently-denied path was not triggered.
5. Everything else matches the design: Start (filled primary, 56dp, play icon) plus the helper "You'll get a quick check-in every 5 min. Answer with one tap.", outlined Stop with no confirmation, the pending-card tokens and captions, the answer-confirmation copy and colours, the snackbar copy, and the pending time in the system 12-hour format.
